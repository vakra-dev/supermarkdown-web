# supermarkdown-web

Website and documentation for [supermarkdown](https://github.com/vakra-dev/supermarkdown) - an HTML to Markdown converter.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Tech Stack

- Next.js 14 (App Router)
- Tailwind CSS
- Monaco Editor
- @vakra-dev/supermarkdown-wasm
